# Lunar Light Awakening

Astro site for Lunar Light Awakening, a wellness and crystal shop in Schofield, Wisconsin.

## Local Development

1. Install dependencies:

   ```sh
   npm install
   ```

2. Start the Astro dev server:

   ```sh
   npm run dev
   ```

3. Build and type-check:

   ```sh
   npm run build
   ```

The current site is static and does not require server-side environment variables.
